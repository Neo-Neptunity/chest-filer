# チェスト・ファイラー 開発用のテスト

MOD 本体は `chest-filer/mod/`。配る zip に入れたくないので、テストは本体に置かず、ここにまとめる。
どれも EP_MODs から流す。`browser.mjs` は Edge（なければ Chrome）が要る。

| ファイル | 内容 | 使い方 |
|---|---|---|
| `unit.mjs` | 画面を持たない部品の試験。仮想ディレクトリ（入れる・動かす・入れかえ・チェストの中のチェスト・部屋・ホットバー・元に戻す・整頓・さがす）、保存と読み込み（壊れた保存も）、保存の部品（変わったものだけ書く・順序・書けないとき）、**乱数で 4000 回の操作を重ねても木の決まりが破れない**。3D のワールド：地形（台座・入口・窓・たいまつ）、光（1 ずつ弱くなる・窓から入る・ブロックの中には入らない）、面づくり（すべての頂点が正しい・三角形の数）、歩く・ジャンプ・走る・ぶつかる・入口から外へ・チェストを狙う。manifest と書き方の決まり（禁じた呼び出しが無い・画面の文章に全角の括弧が無い・使う機能が uses にある） | `node chest-filer/dev/unit.mjs` |
| `browser.mjs` | 本物の `index.js` を、ヘッドレスの Edge で動かして、本物のマウスとキーを送り、画面を PNG に撮る。WebGL2 はソフトウェア描画 | `node chest-filer/dev/browser.mjs [出力フォルダ] [--scenario=…] [--w=1280 --h=760] [--dpr=2]` |
| `walk-scenarios.mjs` | 歩く見かた（一人称の 3D）の場面。browser.mjs から呼ばれる | |
| `fake-host.mjs` | 偽の explorer_plus。メモリの中の Windows 風フォルダ。ID が合わなければ断る・名前を変えても ID は同じ・`resolve` は消えたものを null で返す | |
| `seed.mjs` | 試験用の種。書類 25 個・写真・音楽・フォルダ、にぎわうワールド（チェスト 8 つ・入れ子・ホットバー） | |
| `cdp.mjs` | ヘッドレス Edge の操作の部品。終わったら描画の子プロセスまで止める | |
| `stage.mjs` | MOD のファイルを一時フォルダにコピーして、node で読めるようにする | |

## browser.mjs のシナリオ

俯瞰（`prefs.mode = "iso"`）
- `look`：部屋 → チェスト → 中のチェスト → 持ち物だけ → 夜 → アイコンだけ → 狭い画面。見た目を調整するときに使う
- `flow`：持ち物から入れる・動かす・入れかえ・チェストの絵の上に落とす・複数選ぶ・Shift+クリック・元に戻す・見出しに落とす・名前を直す・保存
- `room`：部屋で動かす・重ねて入れる・向き・拡大・ずらす・部屋のチェストへ直接落とす・右クリックでこわす・種類・置く
- `hotbar`：数字キー・登録・並べかえ・外す・チェストへは落とせない・検索
- `host`：見つからない参照・名前の変更を追いかける・本体のメニューの名前の変更・ごみ箱への反映・フォルダを移る・下の階層・メニュー（本体が断ったとき）・設定の切りかえ
- `edge`：はじめて・壊れた保存・3000 個のフォルダ・全選択して入れる（上限）・保存できない

歩く（`--scenario=walk…`。偽のポインターロックを使う）
- `walkBasic`：はじめのクリックを待つ画面・固定・W A S D・ジャンプ・走る・見回す・実際のマウスの動き・固定が外れたとき
- `walkUse`：狙う・ヒント・右クリックで開く・開いているあいだは歩けない・見えているチェストへ直接ドロップ・Esc・持ち上げる・台座へ置く・元に戻す・Q・重ねて入れる・台座に新しいチェスト・ぶつかる・飛ぶ
- `walkWorld`：外の草原・空・夜・検索で連れて行かれる・ホットバー・V で俯瞰と往復・見かたの保存・固定できないとき（矢印キー）
- `walkSystem`：歩くでのドラッグ・見えているチェストへのドロップとクリック・何も無い所で閉じる・E・R・上の帯のボタン
- `walkMenu`：F で、狙ったチェストのメニュー

## 確かめられないこと

- 本物の explorer_plus の中での動き。偽の本体と偽のポインターロックで代用している。とくに、ポインターの固定の手触り・マウスの感度・キーが MOD の画面へ届くか・メニューの出かた・アイコンと縮小画像・`resolve` の速さ
- 本物の GPU での速さ。ヘッドレスはソフトウェア描画
